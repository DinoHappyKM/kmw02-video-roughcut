# 橫直式視覺與資產工作流

版本：0.5.0｜2026-11-20｜[製作流程](WORKFLOW.md)

本檔是橫直式版型、素材 fallback、開窗與落點、示意圖、字卡、封面及聲音素材選用的通用規則主檔。與本檔衝突的舊 30:60 固定風格、固定座標只適用於選定該 preset 的作品。原始素材、同步、字幕審校、人工修改保留、混音檢查與 XML 交接沿用既有流程。作品明確指示優先，未知名詞先問。

## 開始一支新作品

1. 讀最新工程與需求卡；盤點拍攝素材與共用庫，原始媒體唯讀。A-roll 是敘事角色，B 機不是必然的 B-roll；多機關係要有證據。
2. 只補問未知的比例、內容目標與交付。可選橫式 16:9、直式 9:16 或兩版；時長依作品要求與內容完整度決定，不為湊秒數斷句。
3. 盤點背景／示意圖畫風、公仔、字卡三要素，以一張組合樣張確認美感；已有明確授權或選定參考就沿用，不重問整份問卷。
4. 先完成內容地圖、主內容與同步，再依段落做定位、示意圖、標題字幕、配樂及音效。主內容變更後重驗受影響項目。
5. 逐版本檢查實際輸出與完整播放；文件寫好、工程設定、抽圖、實機播放、Owner 驗收與學生重現分開記錄。

## 版型

| 模式 | 內容配置 | 需記錄 |
|---|---|---|
| 橫式 | 影片窗與右側示意圖；30:60 繪本是可選 preset | 本片窗位、字卡字幕安全區；新參考可換風格 |
| 直式基本版 | 上方一個近正方形影片窗，中間影片標題，下方故事示意圖／公仔／主次標 | **A／B-roll 在同一個視窗依內容切換**，不是預設同時雙畫面；精確比例與字幕位置由樣張確定 |
| 自訂背板 | 沿用內容層級，以本次喜好圖設計開窗 | 參考圖、洞位形狀、內側安全範圍、邊緣樣式與層序 |

橫轉直要逐段重新構圖，不能直接縮放 1920×1080 舊座標。字幕以輸出畫布水平置中，另留不碰影片窗、字卡、公仔與平台介面的安全位置。

## 資產來源與目錄

盤點時接受既有 `A-roll`／`A roll`、`B-roll`／`B-Rool` 等名稱，記實際路徑，不為符合範本改名或搬素材。單片通常有 A-roll、B-roll、字卡、IP公仔、BGM／音效、封面、示意圖畫風；共用根目錄由使用者指定，不能寫死裝置路徑。

| 類型 | 順序與缺件處理 |
|---|---|
| 公仔 | 本片 IP公仔 → 共用 IP公仔；都無則問提供、省略或製作，不自創品牌角色 |
| 示意圖畫風 | 本次指定風格 → 共用預設畫風 → 索取喜好圖片；不要默認 AI 常見畫風 |
| 字卡 | 本次／已指定預設範本 → 共用字卡；無範本則先問可否一般字體製作，已全權授權者沿用授權 |
| 封面 | 本次明確封面 → 共用封面範本 → 本片示意圖畫風 → 再索取喜好參考 |
| BGM | 現有共用 BGM 庫選曲，按全片時長取片段／整曲／重組；缺件回報 |
| 新製音樂／音效 | Suno 是 Owner 已指定的未來製作方向；本片是否生成、與共用庫順序、成品入庫位置另記，不默認已接入或每片必生成 |
| Logo | 用提供的原圖；是否出現依作品，不重新繪製品牌字 |

每項記本片／共用來源、參考或實際入片用途、選中路徑及版本。找不到才索取，已給的本片素材不能被共用庫覆蓋。

## 示意圖、風格與文字

用畫面呈現原稿的表象、真相或內涵；生成示意圖不能冒充實際事件或人物成果。先拆參考圖的構圖、留白、色彩、筆觸、材質及文字層級，再做同組示意圖與封面。可請使用者從 Vivisticker 或黃嘉偉 KM 的 Pinterest 提供喜好截圖；未看見圖片不能聲稱已學習。

主標與次標用大小、粗細及位置建立層級，避免所有文字搶重點。標題、段落重點、片頭、片尾和逐字字幕分開設計。片頭先確定看點，片尾依故事收束共鳴或真實 CTA，再做美術與停留時間。

本包附 [IPE 動態透視漸縮字形 v2](lettering/STYLE.md) 與六張參考圖，供本次沒有其他字卡指示時使用：

- `hero_title`：厚重斜切字、左大右小漸縮、可換色斜切底板；底板外真透明。
- `minor_heading`：同系切角純字、大主字＋小輔字；預設深灰黑、無底板、真透明。不自動增加範例文字。
- `title_system`：主標與小次標分開輸出，方便時間線調整。冰藍只是參考配色，不是固定品牌色。

這些是靜態字形的動勢，並非已製成動畫。參考圖不是字型檔；變體有 alpha 不等於可直接當合格去背成品。實際生成要驗字形、裁切、像素尺寸及透明區。

有黃嘉偉 KM 技能時：I0005 做獨立花字、I0008 做參考圖美術、I0012 做頭尾文案。未安裝時直接依本檔與內附規範交接可用工具，不假稱已呼叫外掛。可選獨立 PNG、圖內合成文字或經接受的一般字體；清楚交代可編輯性。

## 開窗與圖層

優先交付已挖洞的真透明 PNG。生成工具洞位不穩時，可先畫美術，再用幾何／灰階遮罩精準挖洞；仍不可行才用不撞色單色區＋色度去背。背板預設不畫死逐字字幕。

分開管理背景、影片、開窗外框／裝飾、示意圖公仔、標題及字幕。背板洞內 alpha=0 露出下層影片；影片自身還要限制於窗內，避免從其他透明裝飾漏出。

硬邊、微柔邊與筆刷邊按參考與內容選。需要對照時可試開窗短邊 0%、0.5%、1.5% 過渡帶，僅為樣張起點。臉、商品、關鍵按鈕必須留在清晰區。用黑／白／高對比底與真實影片疊合，驗證透明、溢色、漏底、吞字與洞位；棋盤格圖案不等於透明。

## 視覺落點

逐段辨識「觀眾必須看到什麼」：人物、商品、手部、操作或多個相關物件。先決定必保護區，再裁切、縮放、平移；需要時使用現有追蹤／關鍵幀，低信心則人工指定。不是一律追臉或幾何置中。

決策表記來源區間、主體、安全窗、縮放／平移／關鍵幀、理由及人工 override。圓形或不規則開窗要檢查實際內側安全範圍，不只看外接矩形。無法同時保主體與填滿視窗時，縮小留白、調窗、換鏡或確認取捨，不裁掉關鍵內容或快速追逐。

各段頭中尾、A／B 切換、運動極值、關鍵幀附近均檢查，最後完整播放；橫式通過不能替代直式通過。

## 聲音與未來接入

音效依本片情緒與時機提案：可愛可偏彈跳／切分／遊戲感，情感可偏緩慢柔和；不是固定模板。未全權授權時先確認感覺，已全權授權可自行安排。BGM、音效或兩者融合皆按內容判斷，保留人聲、自然接縫與尾奏，沿用聲音處理驗收。

KMW10 可評估一般文字、合成音效與教學動畫，但名稱不等於當前可執行。**Motion** 是未來動畫區塊接入方向，具體產品／介面未定；**Suno** 是未來 BGM／音效製作方向，未建本包 API 接口。沒有能力時先用現有靜態分層與共用音樂準備剪輯，不假稱已生成或接入。實際製作時記來源、工具、版本與輸出。

## 封面與驗收

9:16 延展背景；主要標題、人物、商品置於中央 4:5 區域，該區每一邊各內縮 15%（內部寬高各 70%）。1080×1920 示範：中央 4:5 為 x=0、y=285、1080×1350；主內容安全區 x=162～918、y=487.5～1432.5，整數像素向內取整。描邊／陰影也檢查。這是 Owner 構圖偏好，不是所有 IG 版位的規格保證；實際平台另預覽。

交付全幅與中央裁切預覽；檢查角色一致、繁體字、主次標、主體不出窗、透明邊、字幕防撞、人聲混音、素材來源、工程重開與各版完整播放。有 XML 再實際匯入核對；遮罩、追蹤、字體、透明動畫及音效不因 XML 可讀就算可編輯。

## 執行輸出與失敗處理

沿用素材盤點、作品需求卡、剪輯決策與交付表，不另造可變時間線主檔。交付工程版本、成片／字幕、資產使用清單、字圖與開窗素材、來源映射和未解決事項。工具失敗保留目前工程與原素材，回報具體缺口和可行替代；超出既有費用／服務範圍時先確認。
