# IPE 動態透視漸縮字形 Skill

**版本：2.0**  
**涵蓋：主標題（Hero Title）／小次標（Minor Heading）／兩者組合（Title System）**  
**目的：讓 AI 只要讀取本檔與 `references/`，就能理解字形是如何構成、排列、上色、去背與校對，而不是機械式複製一張圖片。**

> 一句話核心：**統一的是「厚重斜切的字形 DNA、手工修形與文字大小節奏」，可切換的是「有無色塊底板、字組階層、配色、字數與透視強度」。**

## 0. 先讀檔案，再決定使用哪個模式

### 0.1 讀取順序（重要）

1. 讀完整份 `SKILL.md`。
2. 實際開啟 `references/style_reference_original.png`，觀察原始**主標題**字形與斜切色塊。
3. 實際開啟 `references/variant_02_tapered.png`，觀察最明顯的**左大右小透視漸縮**；其他三個變體只在需要時開啟。
4. 實際開啟 `references/minor_heading_transparent.png`，觀察**小次標**的上下兩層大小關係、傾斜、筆畫形狀，以及**沒有底板、背景透明**的做法。
5. 使用者有提供新參考、新文案、新配色或用途時，優先遵從本次指示，再以本 Skill 補完未定義細節。
6. 若執行環境不能讀圖，只能依本文的文字定義執行；**不得聲稱已看過圖像**。

此資料夾存的是**美術字的視覺規範與圖片參考**，不是 TTF/OTF 字型檔。AI 應重現其設計邏輯，不宣稱辨識到特定現成字體，亦不保證每次出圖完全同形。

### 0.2 模式選擇

| 模式名稱 | 代碼 | 核心結構 | 是否有底板 | 預設輸出 |
|---|---|---|---|---|
| 主標題 | `hero_title` | 粗重動態字＋左大右小＋斜切色塊 | **有**（可換顏色） | 透明背景 PNG，保留色塊 |
| 小次標 | `minor_heading` | 純字、切角、傾斜；大主字＋小輔字 | **沒有，禁止自動添加** | **深灰近黑字、透明 PNG** |
| 組合排版 | `title_system` | 依需求把主標題和小次標製成一致字形的兩個層級 | 主標題可有；小次標沒有 | 優先分別輸出透明素材；必要時再合成 |

判斷方式：使用者說「主標、大字卡、斜切底板、活動標題」→ `hero_title`。說「小次標、小標、次級標題、純字、不要背景框、去背黑字」→ `minor_heading`。兩種都要時 → `title_system`。

**概念不要混淆：**主標題字卡內部的第二行文字，仍屬於 `hero_title` 的內部文字；本文的 `minor_heading` 則是一個**可以單獨放在海報上的獨立純字素材**。

## 1. 兩種模式共同的字形 DNA

### 1.1 筆畫構造

- **骨架：**厚重、緊湊的黑體系展示字（display lettering），不是制式電腦黑體直接排字，也不是宋體明體、毛筆行書或可愛圓體。
- **邊角：**明顯的**斜切端點、楔形尖角、不等長的刀鋒式收筆**。部分筆畫可外伸，形成向前推進的速度感。
- **筆畫粗細：**以粗筆為主，但轉折、豎畫、長橫與尾端不必完全等粗；要有**人為修字**的張力。
- **字面：**適度緊縮字距、壓縮或拉長局部筆畫；每個字可有微幅不同高度與傾斜角，避免僵硬的四方格排法。
- **負空間：**字內孔洞及相鄰筆畫間的白縫仍需清楚，不能因過度加粗而全部糊成一團。
- **動勢：**整組字可略向右上方推進，主要用字高、基線、切角與疊合節奏製造動感，不是單純把標準字體全行旋轉。
- **質感：**小範圍裂痕／缺口／飛白可作為選配；純字小次標通常更克制，以清晰輪廓優先。

### 1.2 不可改變的底線

1. **文字內容必須逐字吻合**使用者提供的繁體中文、英文、符號及順序；不自動改成簡體，不自動「校正」陌生用詞。
2. 切角不能切掉辨識某個字所需的偏旁、轉折或收筆；銳利不等於少筆畫。
3. 每個字都要能讀，不能讓壓縮透視造成某個字擠成難以辨識的形狀。
4. 不預設發光、厚重 3D 立體、金屬、大片陰影、邊框；這些只有使用者另外指定才加入。
5. **允許顏色變化，但要保留字形特徵。**同樣的字形可以是黑、白、紅、綠、金色等。

### 1.3 大小與比例不是「放大縮小整張圖」

- 先將文案拆成字或語意字組，建立**每一字／字群的獨立大小**。
- 接著調整其**視覺重心、字距、上下交錯、斜度與階層**。
- 最後才加入底板（主標題）或純字定位（小次標）。
- **不可**只把普通文字打完後，對整張圖片做水平拉伸、四角透視扭曲，冒充逐字漸縮。

## 2. 模式 A｜主標題 `hero_title`

### 2.1 主標題的構成

主標題 = **動態厚重字形 + 左大右小的透視漸縮 + 不規則斜切底板 + 可選的微量磨損**。

參考：
- `references/style_reference_original.png`：核心原圖；主標題可大幅跨越色塊上下邊緣，整組呈傾斜動勢。
- `references/variant_02_tapered.png`：更強烈的從左大到右小，呈楔形收束。
- `references/variant_01_classic.png`、`variant_03_swoosh.png`、`variant_04_burst.png`：其他構圖變體。

### 2.2 文字的漸縮節奏

以**字的視覺高度**作相對比例（可依字數調整，非硬性實測）：

| 透視強度 | 左端主字 | 中段字組 | 右端收尾字 |
|---|---:|---:|---:|
| `subtle` 微透視 | 100% | 85% | 70% |
| `standard` 標準 | 100% | 75% | 55% |
| `strong` 強透視 | 100% | 65% | 40–45% |

使用一行或兩行都可以。前端重心最強、後端漸縮，但**每一行需要獨立排版**，不能機械套用完全相同的縮放曲線。尾端文字太小時，要提高尾端尺寸、放寬間距或改斷行。

### 2.3 色塊底板的形狀

- 底板為**不規則梯形、斜切多邊形、斜向楔形**，不是標準矩形資訊框。
- 頂邊、底邊可略有不同角度，左右端可一寬一窄，局部留有切角或延伸尖端。
- 底板通常只有一個主色塊；可用幾何切片、短速度線點綴，但不喧賓奪主。
- 讓大字適量**超出底板的輪廓**製造層次，字形與底板都不能被畫布裁斷。
- 底板在成品裡是**不透明或有明確色彩的圖形物件**；所謂「透明 PNG」指的是**底板外部的畫布透明**，並不是把色塊也去掉。

### 2.4 主標題變體

- `classic`：比較密集、雙行錯位、斜切色塊與大字相互交疊。
- `tapered`：**預設推薦**；左側主字特大，往右明顯收斂，色塊跟著形成透視楔形。
- `swoosh`：小量弧形或流線，強調字組流動方向。
- `burst`：在外緣加入少量銳角速度線或爆裂切片，不破壞字形。

### 2.5 色彩規則

**原始圖的黑字＋冰藍色塊只是「某次配色範例」，不是固定品牌色。**

| 參數 | 定義 | 預設行為 |
|---|---|---|
| `text_color` | 主字顏色 | `auto`，由底板明暗決定高對比配色 |
| `base_color` | 斜切底板顏色 | 依本次品牌、活動或使用者指定 |
| `accent_color` | 少量線條／切片顏色 | `auto` 或 `none` |
| `texture_intensity` | 磨損程度 | `low` |
| `background_mode` | 底板以外背景 | `transparent` |

換成紅、綠、粉、黑、金或其他顏色後，**字形、透視與底板切角邏輯要維持一致**。不要因沒有指定顏色就永遠回到冰藍色。

## 3. 模式 B｜小次標 `minor_heading`（本版新增重點）

### 3.1 獨立的純字定位

小次標 = **同系列厚重斜切字形 + 明確的主次字級差 + 有節奏的斜向排字 + 純文字透明去背**。

它與主標題同一家族，但更輕便、好疊到照片或海報上：

- **絕對不要自動生成**色塊底板、標籤框、長方形、梯形、框線或襯底。
- 圖像只有**文字像素**（以及使用者明確要求的極少量字形內磨損）；背景是**真透明 Alpha**。
- **預設顏色為深灰偏黑**，建議近似 `#17181B` / `#1B1D21`；不是固定死色號，若指定其他配色便替換。
- 字體仍然粗重、帶刀鋒切角和略微不規則的筆畫端點，不能退化為普通小字黑體。
- 小次標是**尺寸與資訊層級比較小**，不是一定要用細字、溫柔字或沒有造型的字。

### 3.2 參考範例的真實視覺結構

參考圖片：`references/minor_heading_transparent.png`。

該示例採**兩行純字配置**：

- **第一層：**上方主字「小翅標」——字面最大、厚重、斜切，視覺焦點；字群略向右上方推進。
- **第二層：**下方輔助文字「示範範例」——大小明顯小於主字，位置靠近主字下緣、整體偏左到中段；仍使用同類型粗黑切角字。
- 兩組文字都具有近似方向的傾斜和手工修字感，但**不必同寬**，也不一定要完全置中。
- 兩行之間留出足夠可讀的空隙，不需用底板來區分前後。
- **示例字串不是固定輸出文案。**「小翅標」是該圖片的實際範例文字；「小次標」是本模式的名稱。這兩個詞不同，不能自行互換。生成時一律依使用者本次輸入。

> 注意：上述尺寸是視覺推導的**製作建議**，不是從圖片量測而得的精確字高、角度或向量輪廓。

### 3.3 小次標的字級層級：先分「上下層」，再修「字內大小」

小次標建議先做兩層：

| 層級 | 文字欄位 | 參考相對字高 | 作用 |
|---|---|---:|---|
| 大主字 | `primary_text` | **100%** | 先被看見；承擔主要語意 |
| 小輔字 | `support_text` | **40–60%**（預設約 50%） | 補充說明、示範、定位 |

小輔字仍是粗體切角字，不要變成無特色的細小印刷字。若使用者只提供 `primary_text`，就做**單行純字小次標**，不要自動補一行「示範範例」。

**補充的「由大到小」有兩個層次：**

1. **跨層級：**上排大、下排小，這是小次標的**主要視覺比例**。
2. **層內節奏：**同一排可以讓前字略大、後字略小，或對高低、寬度、切角作細微調整（建議 `100% → 90% → 80%`，而不是每一字都一模一樣）。

小次標預設採**適度漸縮**，不要強到最後一字像註腳。尤其只有 2–4 個中文字時，重點是「字面誇張但清楚、字級有節奏」，不是為透視而扭曲字形。

### 3.4 小次標的位置、斜度、結構

- **主字的整體輪廓：**可呈左低右高的視覺推進；單字高度略不齊、筆畫頂端可有斜角，但要統一方向感。
- **字距：**緊密但不能黏成另一個字；局部可讓尾筆向相鄰空間延伸。
- **副字位置：**預設放在主字下方偏左／中段，距離不要過大；可略向右偏移，營造錯位與層次。
- **副字方向：**與主字維持同一個動勢方向，不另做互相衝突的旋轉。
- **基線：**可做輕微起伏、階梯或往右上升，避免完全工整，但不讓整句失去閱讀秩序。
- **畫布：**四邊保留透明安全邊界；不要因尖銳長筆畫而碰到邊緣。

### 3.5 小次標絕對不要出現的物件

- 任何顏色的底板、彩色帶、漸層矩形、標籤框。
- 白色或黑色實心畫布（這**不等於透明**）。
- 主標題模式常見的大面積速度線、爆炸圖、貼紙白邊、文字外陰影。
- 不相關的 Logo、人物、物品、英文字，或未提供的說明文案。
- 大量磨損顆粒造成主字筆畫殘缺。

### 3.6 小次標可自由改色，但預設黑灰

- `minor_text_color` 預設 `#17181B`，輸出時可用一致深灰黑，或有非常輕微的字內明度差。
- 使用者指定白色、奶油色、深綠或其他品牌色時可調整，但**改色不等於加底板**。
- 若小次標要放在深色海報上，視需求可改淺字；仍以「純字去背」交付。
- 如果使用者想做**同一套字型多配色**，應保留同一字形和字級位置，只替換顏色。

## 4. 主標題與小次標的關係

| 項目 | 主標題 `hero_title` | 小次標 `minor_heading` |
|---|---|---|
| 字形 DNA | 厚重、斜切、銳角、手工修字 | **相同** |
| 文字大小節奏 | 左大右小、強烈透視 | 上排大下排小；內部可微漸縮 |
| 顏色 | 隨專案，自由替換 | 預設深灰近黑，可更換 |
| 底板 | **有**，不規則色塊 | **無，禁止添加** |
| 文字層級 | 活動名稱、主視覺重點 | 補充短標、段落引言、小型字卡 |
| 畫布背景 | 預設去背，僅底板外透明 | **全部去背，只留文字** |
| 細節表現 | 可有少量磨損、切片、速度線 | 更克制，以純字筆畫輪廓為核心 |

當兩者同時出現在海報上，**小次標應當輔助主標，而不是再次搶走所有視覺重量**。可以先各自輸出 PNG，再由海報排版系統決定相對尺寸與位置。

## 5. 標準輸入格式與預設值

### 5.1 主標題範例

```yaml
mode: hero_title
main_text: "你的活動主標題"
subtitle: null             # 主標題色塊內的次行，可省略
layout: tapered            # classic | tapered | swoosh | burst
perspective: standard      # subtle | standard | strong
text_color: auto
base_color: "由專案或使用者指定"
accent_color: none
texture_intensity: low     # none | low | medium
background_mode: transparent
output_format: PNG
```

### 5.2 小次標範例（對應參考圖）

```yaml
mode: minor_heading
primary_text: "小翅標"
support_text: "示範範例"
minor_text_color: "#17181B"
primary_scale: 1.0
support_scale: 0.50         # 建議 0.40–0.60，視字數與清楚度微調
within_line_taper: subtle  # none | subtle | standard
baseline_motion: up_right  # 原則為向右上推進，按實際字形調整
texture_intensity: none    # none | low
background_mode: transparent
include_base_shape: false  # 小次標必須為 false
output_format: PNG
```

**重要：**上方的「小翅標／示範範例」只是重現剛才參考圖片時的文字。若使用者要的是「小次標」，**應輸出「小次標」，而非自動替換為「小翅標」**。

### 5.3 使用者最少需要提供什麼？

- **主標題：**有主文字就可以製作；未指定配色時採適合該次用途的高對比配色。
- **小次標：**有 `primary_text` 就可以；`support_text` 可以空白，不自行創作文案。
- 使用者未要求版型、尺寸、顏色時，依本檔預設值處理，不反覆要求已知資訊。

### 5.4 優先權

**本次使用者指定內容／色彩／輸出 > 原始參考圖的字形特徵 > 本檔模式規範 > 變體參考圖 > 生成器自由美化。**

若要求與模式預設衝突（例如「小次標要白字」），**尊重明確要求**；但若只是「小次標」而沒特別說，**預設黑灰純字、去背、無底板**。

## 6. 實際製作流程（可當作執行 SOP）

### Step 1｜先判斷模式

- 讀取本次文案，識別 `hero_title` / `minor_heading` / `title_system`。
- 把使用者提供的字串**原樣保留**，不可因示例內容而替換。
- 對模糊或容易混淆的字（例如「小翅標」和「小次標」），**以本次輸入為準**；真不清楚才詢問。

### Step 2｜設計字形骨架

- 確保每個繁體中文字的基本部件完整、可讀。
- 畫出厚重骨架，再加斜切端點、楔形尾筆、少量不規則輪廓。
- 同一字組的風格要協調，不做成每個字不同字體。

### Step 3｜安排字級與動勢

- `hero_title`：重點在**左大右小**，整體透視逐級收束。
- `minor_heading`：重點在**上排主字大、下排輔字小**；相同字形語言、相同前進方向；層內可以適度前大後小。
- 個別調整大小、位置、間距與基線，禁止一鍵拉伸整張字組造成變形。

### Step 4｜套用形狀與顏色

- `hero_title`：**加入**不規則斜切底板，使用本次設定的 `base_color`，並維持文字清楚對比。
- `minor_heading`：**不加入**任何底板，預設近黑色純字。`include_base_shape = false` 不得被忽略。
- 所有換色都只能改變視覺色彩，不應改動字形與主要尺寸階層。

### Step 5｜材質與細修

- 看小尺寸預覽：辨識度不佳就先減少磨損或字距擁擠。
- 主標題可有少量斑點、飛白、速度線；小次標通常以零或少量細節為佳。
- 確保沒有額外 Logo、英文、背景框或裝飾物件。

### Step 6｜輸出與技術檢查

- **首選 PNG + 真透明 Alpha 通道**（不是白底或棋盤格印在圖上的假透明）。
- 若輸出的是 `hero_title`，斜切色塊仍保留，只有**畫布其他位置透明**。
- 若輸出的是 `minor_heading`，除了字形及必要的字內細節以外，**全部透明**。
- 保留四周安全距離，檢查字筆尖沒有被裁切。
- 依實際用途選尺寸；若印刷尺寸／解析度工具不支援，應明說，不可假稱輸出已符合印刷規格。
- 嚴格逐字人工目視比對；若有可用字形底稿或字型輪廓，優先用輪廓製作／精修以提升正確性。

## 7. 可直接使用的生成提示詞

### Prompt A｜主標題

> 請以 `references/style_reference_original.png` 為主字形參考，並以 `references/variant_02_tapered.png` 參考左大右小透視漸縮的排版。把使用者提供的精確文字「{main_text}」設計成原創繁體中文展示字。使用厚重緊湊的黑體骨架、刀鋒式斜切收筆、銳角、手工修形與少量磨損。字組由左到右依序縮小，整體有向前推進的斜向動勢。字後方使用**不規則斜切梯形／楔形底板**，其顏色使用本次 `{base_color}`，字色 `{text_color}`，**不要固定用藍底**。使用 `{layout}` 變體，透視強度 `{perspective}`。如提供副標才放置「{subtitle}」。不要擅自加字、改字、加 Logo、人物或多餘裝飾。畫布底板外為**真透明**，完整保留字和色塊，輸出 PNG。

### Prompt B｜小次標（重要）

> 請以 `references/minor_heading_transparent.png` 為主要風格參考，為使用者提供的精確文字製作**純字小次標**。第一行主字「{primary_text}」最大且最醒目，第二行輔字「{support_text}」（若有）縮小到約主字的 40–60%，放在主字下方偏左至中段，兩行共享輕微向右上推進的動勢。使用**厚重、銳角斜切、刀鋒式收筆、略不規則的黑體美術字**，可以做少量字內大小節奏，但務必保留中文字每一筆的辨識度。預設字色深灰近黑 `{minor_text_color}`，或使用本次指定顏色。**禁止任何底板、色塊、外框、貼紙邊框、白底或背景圖。只保留文字，輸出有真正 Alpha 透明的 PNG。**不要加入未提供的字句或其他裝飾；四周留透明安全邊界。

### Prompt C｜同一套主標題＋小次標

> 使用本資料夾同一套粗重斜切、手工修字、漸縮動勢設計語言，**分別輸出兩張透明 PNG**：第一張為 `{main_text}` 的主標題，使用指定顏色的不規則斜切底板；第二張為 `{primary_text}`／`{support_text}` 的小次標，**只留深灰黑或指定色文字，不要底板**。兩張字形風格一致，但尺寸層級與底板規則不得混淆。

## 8. 交付前檢核表

### 8.1 通用

- [ ] 逐字確認繁體字、字序、字數、空格與標點；沒有 AI 自動錯字。
- [ ] 保留厚重黑體骨架、刀鋒切角與自然不規則的手工修形。
- [ ] 大小層級清楚，沒有全排等大、等角度的制式排字感。
- [ ] 文字可讀、筆畫完整、負空間清楚，沒有過度碎裂或交疊。
- [ ] 沒有加上使用者未指定的內容、Logo、人物、背景。
- [ ] 畫布四周有安全邊距，筆畫尖端不裁切。
- [ ] 輸出格式是 PNG，透明像素已實際驗證；未驗證就如實標註。

### 8.2 主標題專用

- [ ] 明顯的左大右小透視漸縮。
- [ ] 有不規則斜切多邊形底板，文字可跨越底板邊緣。
- [ ] 底板顏色依本次需求，**不是自動套冰藍色**。
- [ ] 色塊以外的畫布透明；底板本身仍看得見。

### 8.3 小次標專用

- [ ] **沒有任何底板、邊框、色帶或背景。**
- [ ] 主字大、輔字小，原則約 100% : 40–60%（可依字數微調）。
- [ ] 文字保持同一個斜向動勢，筆畫仍有斜切張力。
- [ ] 預設深灰近黑色；若使用者指定色彩，遵從新色。
- [ ] **字形以外區域是真透明**，不是白底、棋盤格或黑底。
- [ ] 只有主字時，沒有擅自增加「示範範例」等文字。

### 8.4 發現錯字或輸出問題時

1. 先回到**精確文字字串**，確認哪個字的部件有誤。
2. 優先局部修字／使用可靠字型字形轉外框修形；必要時重生整張。
3. 修正後再次全圖校對，不可把未確認的字型稱為正式完稿。
4. 生成器做不到透明 PNG 時，必須明確告知；只能在實際完成去背與檔案檢查後宣稱「已去背」。
