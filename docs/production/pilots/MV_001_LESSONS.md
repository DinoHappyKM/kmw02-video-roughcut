本頁只保存匿名、可重用的經驗；實際素材路徑、台詞、工程 ID、操作日誌與交付檔留在忽略的 production-work。使用者已確認第一批三種交付可用，並確認限定達芬奇的 callback 修訂通過；不外推為所有素材、格式或效果都已驗收。

## 已確認的工作規則

| 回饋 | 後續行為 |
|---|---|
| 分析完沒有先討論就開始剪 | 提供具體方案，使用者確認後才剪；助理公告不是使用者同意 |
| 未先詢問交付方式，增加不需要的操作 | MP4／ChatCut／DRT／其他採複選；只製作所選，額外應用程式回匯、播放或渲染另記範圍 |
| 成對音軌難以理解與修改 | 優先每來源一條立體聲；拆 L/R 為需事先說明的備案 |
| 未使用的人聲仍要能恢復 | 每段入選畫面同源同位原聲完整保留、預設靜音；處理口白另軌 |
| 同一句台詞重播卻感受不到 callback | 台詞出現時讓新動作或關係變化承接，不能只把舊句貼到不相關畫面 |
| 結尾口白太小聲 | 核對關鍵句可聽度；有清楚的同句來源時可建立副本，保留原音、不冒充新演出 |
| 使用者只要改達芬奇 | 讀最新時間線，先備份、另存版本，只改受影響段落；其他產物不重做 |
| 新增轉場要落在音樂踩點 | 記錄實際拍點、轉場視覺重心與影格誤差，聽感核對；本規則新增，尚未回頭測已有作品 |

## 工具限制與核對方式

- 先 probe 媒體。檔名無字幕仍可能有字幕軌；主唱與伴奏分軌不可把其中一條冒充完整歌曲。
- 原生 FCPXML 可建立 stereo，但有混放內嵌原聲與口白的情況；原生 OTIO 的 Audio Type、Channels 與來源位置可供重分軌。實際匯出必須是原生 DRT。
- Live Save 可能保存工程操作。未呼叫 SaveProject 不代表沒改動；使用獨立交接工程或其版本副本，保留既有時間線。
- 工程設定參數不等於實際生效。這批 ChatCut 的保存／預覽影格率有差異，最終採30fps且維持秒數；MP4／DRT為24fps，差異已揭露。這不是所有 ChatCut 任務的固定要求。
- 建立時 Text+ 回傳成功，不能證明保存後或交付 DRT 中仍可改字。本批實際字幕包含圖卡／透明影片素材；需據實標示，不能沿用「四張可編輯 Text+」的概括承諾。
- 靜態圖片附加 API 可能忽略指定時長，使用預設五秒；此批限定字幕用精確影格透明素材處理。素材是交接相依，不是額外驗證成片，交付須說明保留。
- 技術設定、抽查影格、全片解碼、完整聽感及使用者情緒驗收分開記錄；不以局部成功推定完整能力。

## 後續測試

優先測另一批歌曲／素材，以及明確有人工修改後的小範圍接續；實際需要時再測 B類反轉、無間奏口白、補錄對嘴、直式及異機重連結。主選單與新踩點規則先有格式／路徑驗證，實際下一輪行為另記，不現在擴大剪輯。
