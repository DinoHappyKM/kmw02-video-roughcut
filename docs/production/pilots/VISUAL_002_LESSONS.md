# 第二輪直式故事剪輯回饋

日期：2026-11-20｜範圍：技能1視覺包裝；規則主檔為 [視覺流程](../VISUAL_WORKFLOW.md) 與 [包裝規則](../PACKAGING_RULES.md)。本檔保存修訂理由，不另定流程。人物、逐字稿、媒體及工具暫時 ID 留在私人專案。

## 本次實際順序與修訂原因

1. 盤點素材、讀逐字稿，確認直式故事方向及講者署名。
2. 建主內容初稿；使用者指出口頭贅字後再做去贅字版本。
3. 先試放照片；使用者指定只用 A-roll 後移除。
4. 製作一張下方插畫、主標及音樂；使用者要求先看全部字幕再修，據此交有字幕審片，並修正辨識錯字及吞嚥聲誤辨。
5. 使用者指出單張圖不能承載完整故事，要求導演視角的寓意分鏡；完成多段插畫並組接。
6. 後補小次標及窗框時，文字壓到角色，只好移位；頂部平台安全區尚未驗證。
7. 評估實拍後做輕微明暗／飽和校正，輸出新版；保留原版作比較。

主要原因：沒有在繪圖前一起確定主次標、字幕及插畫的空間；已畫好的構圖受到後加文字擠壓。Owner 因此明確要求先定標題與次標的文字及位置，再繪圖。新版程序已納入正式文件，下一作品仍需用真實文字與組合樣張驗證。

## 可重用修訂與界線

| 回饋 | 本次修正／下次處理 | 證據範圍 |
|---|---|---|
| 後補文字壓到插畫人物 | 文字與安全版位先行，代表樣張後才批量繪圖 | 已觀察碰撞與移位；新版預防順序由 Owner 指定，尚待下一作品實測 |
| 一張插畫無法承載敘事轉折 | 先記口白事實、內在情感、畫面寓意、人物動作及時間承接 | 多圖已生成、組接與輸出抽查；完整敘事效果待審 |
| 想先看帶字幕的影片再修字 | 依既有授權先交可修改草稿，未知詞暫標並追蹤 | 已在本片執行及修正，不要求所有新作品跳過審校 |
| 方窗缺少設計整合 | 窗框與文字版型一起設計，裝飾服從素材與參考 | 透明向量窗框已入片及抽查，非每片固定外框 |
| 最後才評估調色 | 保留評估步驟，可記無需調整；參數按素材而定 | 同影格前後與輸出抽查，非全片／學生通過 |

圖片張數、提示詞、停留秒數、字型、窗框形式及調色數值都是案例選擇，不升級為通用固定參數。使用者排除照片是本片需求，不取消技能的 B-roll 能力。KMW07 可提供導演思考，仍保留未安裝時可用的分鏡欄位；不新增強制外掛依賴。

## 待驗證

- 用下一作品驗證文字先行是否減少插畫重畫與版位修正。
- 以真實手機平台介面檢查小次標及字幕安全區；移到頂部不算通過。
- 完整正常速度播放聲畫、嘴型、字幕及所有插畫切換；本次已有抽幀不能替代它。
- 新安裝包的宿主發現、更新及學生環境重現另行驗證。
