# 影片類型與剪輯規則

[入口](../../START_HERE.md)｜以下是選擇策略的規則，不是所有功能已實測的聲明。

| 情境 | 分組／基準 | 主內容判斷 | 特別檢查 |
|---|---|---|---|
| 單機長錄影 → 一部 | 來源完整時間線 | 去錯誤和無效重複，保留整體脈絡 | 句頭句尾、呼吸、意義 |
| 單機長錄影 → 多部 | 共用原始來源，各版本獨立 | 每個主題具前提和結論 | 不從已刪減長版硬拆所有短版 |
| 同場多機 → 一部 | 同步母版＋主音訊 | 內容選取後安排鏡頭 | 嘴型、反應時間、相機重啟 |
| 同場多機 → 多部 | 共用同步母版，各版本獨立 | 每部選題與切鏡可不同 | 修改一部不得波及其他版本 |
| 多次重錄 → 一部 | 按 take 分組 | 選完整且自然的一次 | 不以最後一次或相似台詞決定同步 |
| 口播＋操作錄屏 | 人聲與操作證據對照 | 講到哪個步驟就展示對應操作 | 關鍵點擊、畫面文字與先後順序 |
| 多天、多場活動 | 各場次分別同步 | 依主題或故事重組 | 不捏造時間因果 |
| 多場景微電影 | 場景／鏡次／take／劇本對照 | 表演、資訊揭露、情緒與敘事節奏 | 動作、視線、位置、服裝、道具與聲音連續性 |
| 成片＋補拍 | 原已確認工程另存版本 | 指定替換與補充 | 舊版保留，字幕與配樂重新核對 |
| 沒有共同收音 | 人工可辨識錨點／可驗證時碼 | 先解決同步不確定性 | 未證實前不可列同步通過 |
| 宣導／講座繪本畫中畫 | 30% 左下實拍手繪框 ＋ 60% 右側留白公仔字卡 | 口白重點轉化為溫暖繪本公仔與高對比 POP 字卡 | 先審完整字幕表、確認三要素樣張、提醒生圖模式 |

## 長短版

- 30 秒：聚焦單一重點及必要前提，若有行動邀請需有素材或另行確認。
- 60 秒：一個可獨立理解的主題，保留原因／示範／結果中必要部分。
- 180 秒：可容納完整小教學或較完整故事，不預設等於 60 秒版加長。
- 5–10 分鐘：依內容深度與觀眾需求安排，時長是目標不是強湊理由。
- 橫轉直要重新看臉、操作區、文字與字幕安全區，不只是裁掉兩側。

## 微電影路線

先以一個完整場景做試剪：確認故事意圖 → 檢視各 take → 選表演 → 建立場景敘事 → 檢查連續性 → 人工審片。
通過再擴展到十分鐘作品，預設 DaVinci 精修。不把訪談的「誰說話切誰」直接套用到戲劇。
無對白、刻意停頓與沉默可承載敘事，不能用口播去停頓規則自動移除。

## 30:60 繪本手繪框畫中畫（PiP）套路（宣導／講座／知識短影音）

適用於公益宣導、校園講座、品牌故事、衛教科普與活動精華，將現場實拍講者與文青童趣繪本完美結合：

### 1. 畫面空間黃金配比與圖層架構（16:9 / 1920×1080）
- **V1 底層（米白紙紋背景 ＋ 右側 60% 留白公仔字卡）**：
  - 全畫布鋪設溫潤米白紙紋（`#F4F1EA`），營造繪本呼吸感。
  - 右側 60%（`x: 800 ~ 1850, y: 80 ~ 900`）隨口白主題段落切換「手繪鉛筆素描 IP 公仔 ＋ 黑底圓角手剪 POP 字卡（重點字以金黃 `#F2B705` 點綴）」。不堆疊雜亂的實拍 B-roll 照片。
- **V2 中層（左下 30% 實拍講者視窗）**：
  - 座標固定於 `[x: 47, y: 500, w: 702, h: 395]`，套用 [包裝規則](PACKAGING_RULES.md) 之實拍文青溫暖調色。
- **V3 頂層（左上常駐標題 ＋ 左下手繪雙線鉛筆外框）**：
  - **左上角常駐主題標語**（`x: 47, y: 38`）：由「金黃圓點 ＋ 主辦單位小標 ＋ 粗體主標題 ＋ 副標題 ＋ 極簡金線」構成，全片常駐提供留白設計感與主題辨識度。
  - **左下角手繪雙線鉛筆外框**：以透明 PNG 疊加手繪微抖動雙線外框（四角帶素描交叉出頭筆觸），包覆 V2 實拍視窗邊緣，破除生硬數位切邊。
- **C1 字幕層（底部防撞安全區）**：
  - 固定於 `[left: 288, top: 965, width: 1344, height: 80]`，與左下角影片底緣（`y: 895`）保持 70px 淨空，絕不遮擋影片或公仔。
- **片尾昇華卡（最後 4～5 秒全螢幕寓意卡）**：
  - 口號或結語收束後立即硬切，不留現場拖長雜音；全螢幕米白紙紋呈現手繪小圖示 ＋ 兩句讓大人與小孩皆能省思共鳴的溫暖金句 ＋ 單位署名。

### 2. AI 前置互動與模型調度 SOP（必行四步驟）
1. **先抓美感三要素並出樣張**：動手合成前，AI 必須主動與本人確認 **① 背景紙紋與主輔色、② IP 公仔筆觸畫風、③ POP 字卡排版風格**，並先產出一張 `Style Sample` 合成樣張對齊質感。
2. **主動提醒模型切換與繪圖模式（省額度防呆）**：
   - **企劃討論、逐字稿去贅字審核、MCP 時間軸組裝**：主動提醒本人使用高速輕量模型（如 Flash），快速完成且不消耗高階模型配額。
   - **繪製公仔與字卡**：主動提醒切換生圖模式；若雲端生圖配額受限，立即切換「本機紙紋＋手繪筆觸＋本機華康 POP 字型（DynaFont POP）渲染腳本」，零配額消耗且繁體字 100% 精準無錯字。
3. **先審完整字幕表再上片**：依 [包裝規則](PACKAGING_RULES.md) 11 條鐵律，先將去贅字、修錯字後的完整時間軸字幕表一次列出供本人確認，確認後才寫入工程。
4. **自動完成聲音等化與 BGM 混音**：自動套用分段人聲增益平衡、10 幀接縫交叉淡化、總響度 `-20 ~ -22 LUFS` 控制，以及 BGM `-20 dB`（佔比 20%～30%）頭尾淡入淡出。
