# 技能1：多機訪談與宣導講座剪輯（含 30:60 繪本畫中畫套路）

這是儲存庫內的技能入口，通用規則唯一來源在 docs/production。使用時須保留整個儲存庫的相對路徑；不要只複製此技能資料夾當成完整學生安裝包。

MV 歌曲與情境素材任務先走 [技能2：MV 情緒敘事剪輯](../mv-emotional-editing/SKILL.md) 及其專用流程；剪前確認、交付選擇與應用程式操作範圍優先適用。技能1雙機訪談流程保留。

輸入「0」或「主選單」時，先走 [影片主選單](../video-workflow-menu/SKILL.md)；這只顯示技能，不重設或修改現有工程。

## 先讀與確認

閱讀 [工作入口](../../START_HERE.md) 與 [狀態](../../docs/production/STATUS.md)。接續剪輯時依 [製作流程](../../docs/production/WORKFLOW.md) 讀目前工程與目標時間線；不能以舊輸出代替目前人工修改。ChatCut 連線以實際 get_active_project／read_project 驗證；連線未成功則處理 [連接與交接](../../docs/production/SETUP_AND_HANDOFF.md)，不假稱已接手。

## 依本次任務工作

- 新素材或新版本：盤點素材與內容地圖，沿用已確認方向，為每部作品建立需求卡；同場多機保留完整同步母版，成片使用獨立時間線。套用 [影片類型規則](../../docs/production/SCENARIOS.md)；普通疊軌不宣稱原生 Multicam。
- 字幕、補充畫面、封面、聲音或審片修改：先讀 [包裝與修改規則](../../docs/production/PACKAGING_RULES.md)，再限定本次修改範圍。該文件記錄本專案已確認的預設；作品另有明確指示時更新需求卡。
- XML／DaVinci 交接：主動讀 [素材自檢與必要轉檔](../../docs/production/XML_HANDOFF_RULES.md)，分辨媒體讀取、來源引用及功能轉移；在授權範圍檢查素材、建立必要副本、更新實際時間線引用、匯出後核對 XML，再完成目標軟體驗收。字幕、效果和聲音另訂交接方案，不能靠轉檔宣稱全部可編輯。
- 只整理測試回饋：不改時間線或素材。參考 [首輪回饋](../../docs/production/pilots/PILOT_001_LESSONS.md)，將新回饋轉成適用規則、證據狀態及 [回歸案例](../../docs/production/TEST_CASES.md)，同步相關工作表；不因一次缺口直接開發新引擎。

## 驗收與記錄

主動執行 [包裝規則的交付前自我檢查](../../docs/production/PACKAGING_RULES.md)：字幕單行置中、人聲降噪與副作用、繁中字形及適合影片的字型都是必檢項目；不通過先在已授權範圍修正並重驗，記錄證據或明確待審原因，不等使用者再次提醒。

逐份核對使用者指定及本次交付的時間線版本，記錄已修正、原本符合或未處理；字幕需讀完全部頁面並核對有效文字框，不能以新版通過代替另一份包裝稿。參考包裝規則的逐版本核對。

有 XML 需求時，以上自我檢查還要涵蓋媒體規格與來源對照、全部片段是否實際使用新副本、匯出檔引用與目標軟體播放。可驗證的先做；需要人工播放的項目附具體測試位置，不冒充已通過。

用 [交付檢查表](../../docs/production/templates/04_DELIVERY_CHECKLIST.md) 核對實際輸出與既有人工修改。明確區分設定核對、畫面抽查、完整播放、使用者驗收及學生重現；未執行保留待測。保持原始媒體、來源追蹤與其他作品完整。私人素材、逐字稿、人物資訊及工具暫時 ID 保存在本機，不寫入通用技能。

本技能不提供隱含的 GitHub 發布、安裝或時間線修改授權，執行範圍依目前使用者請求決定。

## 聲畫與情緒剪輯｜0.2.0

完整剪輯、重剪、MV與剪法診斷，先讀[情緒表達剪輯](../../docs/production/EMOTION_EDITING.md)做表達需求檢查，依聲畫證據、素材品質與可用工具選鏡、調度B-roll／字卡／聲音並記錄執行結果。只修字幕或整理回饋限定本次範圍。新MV方案、人工修改及交付仍遵循上方原流程。

## 30:60 繪本手繪框畫中畫套路與 11 條通用鐵律｜0.4.0

- **宣導／講座／知識短影音（30:60 繪本畫中畫套路）**：依 [影片類型規則](../../docs/production/SCENARIOS.md) 執行「左下 30% 手繪雙線鉛筆框實拍視窗 `[x:47, y:500, w:702, h:395]` ＋ 左上常駐主題標語 ＋ 右側 60% 米白紙紋留白搭配鉛筆素描 IP 公仔與黑底金黃 POP 字卡 ＋ 底部 `top:965` 安全區字幕 ＋ 片尾全螢幕溫暖共鳴金句卡」。動手前必先向使用者確認「背景、公仔、字卡」三要素並出樣張，且主動提醒切換對應模型／繪圖模式以節省配額。
- **11 條通用剪輯與混音防呆鐵律**：依 [包裝與修改規則](../../docs/production/PACKAGING_RULES.md) 預設自動執行：字幕先列完整去贅字修錯字對照表供本人一次確認後才寫入、強制繁體正字（攔截隻有／淤青等錯字）、保護片頭倒數與片尾口號起點（`sourceIn: 0` 逐句對齊波形）、剪除走位雜音與尾端過渡贅詞並緊密貼齊（Tighten）、大段落乾淨硬切、分段人聲響度等化、總混音控制在 `-20 ~ -22 LUFS`、所有剪接點自動加 `10 幀` 音訊交叉淡化、BGM 壓在 `-20 dB`（佔比 20%～30%，頭 30 幀淡入／尾 60 幀淡出）、實拍套用文青溫暖調色（`6800K`、對比 `0.95`、暗部 `+0.08`）。
